# Executáveis do AGRA

## Windows

`windows/AGRA-0.1.0-alpha.1.exe`

Executável portable Electron. Não exige instalação.

## Android

`android/AGRA-0.1.0-alpha.1-debug.apk`

APK debug para instalação e testes no Android.

Os arquivos são cópias dos artefatos gerados em `dist/desktop/` e `android-native/app/build/outputs/apk/debug/`.
